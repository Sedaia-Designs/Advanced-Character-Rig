  HD Skin+Eye Support (Full HD Skins dont work on extruded version)

  FK + Global IK + Local IK Controls for Arms and Legs

Notes:
    SACR is designed to be used with HD skins, as such UV's on the base model are set to match, making Extruding ugly unless you want to fix the UV's yourself.
    
    In SACR V1.1a the Pupils had a Easy UV Control, I am removing this because each HD eye is different, some are shaped differently, and some are not aligned with the 64x64 Pixel Alignment, as such the UV's must be changed Manually through the UV Editor which is why Pupils are left Selectable
    
    Fancy Feet are not in this version, they may appear later on in the future when I learn how to make them, but for now there is none.
