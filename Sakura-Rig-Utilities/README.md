# Sedaia Rig Interfaces

Sedaia Rig Interfaces (formerly Sakura's Rig Interfaces) is a modern, modular Blender extension designed to provide advanced UI controls and management tools for Sakura's Rigs. It features a robust rig-specific property system, streamlined rig and skin management, and a collection of utility operators to enhance the rigging workflow.

---

## Key Features

- **Modular UI System**: Refactored architecture for better maintainability and performance.
- **Rig-Specific Properties**: Settings are stored per-object, allowing multiple rigs to coexist with independent configurations.
- **Rig Manager**: Easily download, append, and manage Sakura rigs from within Blender.
- **Skin Manager**: Import local skins or download them from Mojang, with support for custom names and player profiles.
- **Online Access Management**: Enable online features directly from the UI without digging through preferences.
- **Security Guardrails**: Built-in checks for online functionality to ensure user privacy and safety.
- **Backward Compatibility**: Synchronizes with legacy rig properties to ensure older assets continue to function.

## Installation

### Prerequisites
- **Blender 4.2 or newer** (Supports the new Extensions system).

### Steps
1. Download the latest `.zip` release from the [Releases page](https://github.com/Sakura-Sedaia/Sedaia-Rig-Interfaces/releases) or the [Blender Extensions platform](https://extensions.blender.org/add-ons/sakura-rig-interfaces/).
2. In Blender, go to **Edit > Preferences > Extensions**.
3. Click the arrow in the top right and select **Install from Disk...**.
4. Select the downloaded `.zip` file.
5. Ensure the extension is enabled.

---

## Usage

1. Open a Sakura Character Rig (available at [sakura-sedaia.com](https://sakura-sedaia.com/rigs/sacr)).
2. Locate the **Sedaia** tab in the Sidebar (`N` panel) of the 3D Viewport.
3. Use the **Rig Manager** to fetch new rigs or the **Skin Manager** to apply custom textures.
4. Adjust rig-specific settings in the **SACR R7 UI** panels.
