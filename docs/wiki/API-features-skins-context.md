# `features.skins.context`

[Home](https://github.com/Sedaia-Designs/Advanced-Character-Rig/wiki/Home)

Blender context validation shared by skin panels and operators.

## `skin_metadata`

```python
skin_metadata(context)
```

Return the skin configuration pose bone, or ``None`` when unavailable.

## `has_skin_metadata`

```python
has_skin_metadata(context)
```

Return whether skin metadata.
